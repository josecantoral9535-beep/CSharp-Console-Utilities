# CSharp Console Utilities

A comprehensive collection of functional C# console applications demonstrating solid foundations in algorithms, mathematical modeling, data structure management, string parsing, and Object-Oriented Programming (OOP) principles.

## Portfolio Projects

### 1. Text & String Manipulation
* **Analizador de texto:** Evaluates string properties, executing precise operations to count characters, words, and structural text components.
* **Buscador y Reemplazador de Palabras:** Performs efficient search-and-replace actions within text blocks utilizing string parsing techniques.
* **Validador Contraseñas:** Validates user credentials against specific security policies, assessing length, casing, and special character requirements.

### 2. Logic, Games & Simulation
* **Tamagotchi:** A simulation application leveraging Object-Oriented Programming (OOP) to track entity states, status decays, and real-time life cycles.
* **JuegoAdivinanza:** An interactive logic game that utilizes pseudo-random number generation combined with recursive user-input validation loops.
* **ToDoList:** A productivity utility using local data structures (Arrays/Lists) to perform standard CRUD actions on tasks within a console environment.

### 3. Financial & Mathematical Utilities
* **SimularCredito:** A financial utility designed to compute credit amortizations, apply interest rates, and display structured loan payment schedules.
* **Calculadora_Propinas:** A practical utility focusing on floating-point arithmetic to divide restaurant bills and calculate gratuity percentages dynamically.
* **ConversorMonedas:** A currency exchange engine executing precise mathematical conversions across multiple global currencies.
* **Convertir F C o K:** A thermodynamic conversion engine that implements algebraic formulas to shift between Fahrenheit, Celsius, and Kelvin scales.

### 4. Core Logic & Foundations
* **3 numeros:** A logical sorting script designed to evaluate, compare, and order numeric inputs using conditional branching.
* **Operadores:** A fundamental repository showcasing the implementation of arithmetic, relational, and logical operators in C#.
